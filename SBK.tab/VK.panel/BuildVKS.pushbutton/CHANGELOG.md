## [0.21.0] — 2026-11-02

> База — 0.20.0. Пользователь: изоляция на арматуре воздуховодов — 0 м², «мы же исключаем количество меньше порога».
> По решению 10.10 строки < порога сами не скрывались (только отмеченные). Решение: ноль — скрывать само.

### Строки с количеством 0 — скрываются сами
- `zero_auto` / `ZERO_AUTO_KEYS`: мерные категории (трубы, гибкие, изоляция труб и воздуховодов, воздуховоды,
  гибкие воздуховоды, внутренняя изоляция) — строка с суммой ровно 0 скрывается при сборке без галки; в отчёт —
  «скрыты строки с количеством 0 … проверьте количество в модели». Штучные (оборудование, арматура, фитинги —
  «Число») так не скрываются. Строки 0 < q < порога — как раньше, галкой в окне «Строки < порога»; нулевых в окне нет.
  Оценка листов — так же.

## [0.14.1] — 2026-11-02

> База — 0.14.0. Отчёт 421-1-ОВ (блок 1.4, 02.11.2026): «создана коллекция листов», «добавлен лист 1», затем «нет

### Сбои Revit при записи — не прячутся и не теряются
- Причина (по коду): обработчик сбоев шага убирал только предупреждения; при ошибке Revit открывал своё окно, оно
  оказывалось под окном хода работы (Topmost), сборка ждала его; затем шаг откатывался, а `Commit()` не проверялся —
  коллекция и лист исчезали молча.
- `vks_core.Tx`: обработчик `_Failures` — ошибки Revit → откат шага, текст и id элементов (до 5) — причина отмены
  (`UserError`): «Revit не дал выполнить шаг «…»: … Сборка отменена, модель не изменена.» Итог `Commit()`
  проверяется. Предупреждения по-прежнему убираются, но теперь идут в отчёт одной строкой
  («предупреждения Revit при сборке …», с числом и id). Сбои после отката окном не всплывают (`SetClearAfterRollback`).
- `ensure_section_sheets`: «создана коллекция» / «добавлен лист» — в отчёт только после записи шага.
- `do_layout`: время коллекции и листов — в этап «Листы» (было — в «Позиции»: «Позиции — 37:55, Листы — 0 с»).
- `vks_sections.run`: та же причина без трассировки, предупреждения — в отчёт.
- `vks_anim`: окно хода работы не поверх всех окон (`Topmost=False`) и есть в панели задач — окна Revit видны.
- Шаги, где ошибка и раньше не останавливала сборку (шаблон, таблица материалов), — как были: текст в отчёт.

### Проверено (вне Revit)
- Python 2.7 (parso 0.7.1) — без новых ошибок; CPython — компиляция. Заглушки `Tx`: предупреждения — счёт и id,
  ошибка → `UserError` с текстом, исключение внутри шага — откат и проброс.
- **Не проверено в Revit:** сама ошибка Revit при создании листа блока (какая — покажет новый текст отчёта),
  `ProceedWithRollBack` без окна, окно хода работы не поверх Revit.

- Чипы систем в группах: щелчок — выбрать, Ctrl+щелчок — добавить; выделенные тянутся вместе; брошенные в левый
  список — убираются из группы. В левом списке выделение нескольких систем не сбрасывается при перетаскивании.
- Карточки групп тянутся мышью за свободное место; выбранные группы переносятся блоком; в пустое место — в конец.
- Ctrl + ЛКМ с протягиванием — рамка: выделяет системы в левом списке и чипы, которые задела; Esc — отмена.
- Цвета систем по таблице (В1 #007FFF … К3 #A57C52): квадрат цвета линии + подпись затемнённым цветом; светлые —
  с тёмной кромкой; вентиляция — нейтральный серый.
- Строка названия системы: по умолчанию 8 мм; высота — только на вкладке «Листы», в карточке группы её нет.

### Окно
- Системы: выбор карточек щелчком, Ctrl+щелчок, Shift+щелчок (диапазон), Esc — снять выбор.
- Tab / «Связать» — связка групп (подряд на одном листе), пастельные цвета; «Разъединить связку».
- Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) — отмена/повтор настроек, до 100 шагов, по всем окнам.
- Enter в поле — принять значение; Ctrl+↑/↓ — переставить группы; Ctrl+«+»/«−» — объединить/разъединить.
- Строка полного названия системы (12 мм) с примечанием — галка у группы.
- «Что специфицируем»: ADSK_Количество = 0 — жёлтым.
- «Материалы и типы»: вкладки «Сантехнические приборы», «Сантехническое оборудование» и вкладки воздуховодов.
- «Сортировка»: окно «Строки ≤ порога…» — список, суммы по единицам, галки «скрыть».
- «Листы»: коллекция листов; высота строк 5 / 8 / своя / как в шаблоне; заголовок 8 мм; проверка занятых
  номеров заранее (мягкий красный + жёлтое пояснение); суффикс номера; режимы «Продолжить после листов РП»,
  «С 1-го листа с префиксом или суффиксом», «Начиная с номера»; число листов комплекта в штамп (Да/Нет + число).
- Из заголовка окна и названия шага отмены убрано «SBK».

### Сборка
- Категории ищутся по модели: есть трубы — трубопроводные, есть воздуховоды — вентиляционные (+ оборудование,
  обобщённые модели). Вентиляционные системы; одинаковые сокращения ВК и ОВ — разные группы («В1» / «В1 (ОВ)»).
- ADSK_Количество штучным больше не дописывается (было: пусто → 1) — предупреждение в отчёте. Трубам без
  количества — длина, как раньше. Воздуховоды и их изоляция — только чтение.
- Гибы: соединительные детали с наименованием трубы — в количество трубы, без задвоения при повторном запуске.
- Строки с суммой < 1 — предупреждение в отчёте. Скрываются только строки ≤ порога, не оставленные в окне.
- Связанные группы не начинают новый лист; отступ между группами по умолчанию 0 мм.
- Высота строк спецификации на листе («Изменить размер строк = Все», «Высота строки»), высота заголовка.
- Шаблоны «О_…»: назначение «Трубопроводы», «Воздуховоды», «Вентиляция» или пустое (запасной вариант).

### Не проверено в Revit
Высота строк и строка 12 мм на листе, коллекции листов Revit 2025, штамп, гибы на модели, единый Ctrl+Z.
